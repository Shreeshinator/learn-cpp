Setup, what C++ is, and your first program

Goal: by the end of this page you will have installed a compiler, created a C++ source file, compiled it, and executed it to print Hello, world. Each new term is defined as it appears.

Overview: C++ development uses three components. The source file (.cpp) contains human-readable code. A compiler translates C++ source code into machine code the CPU executes. It does this in three stages: preprocessing, compilation, and linking. The terminal is the interface used to invoke the compiler and run the resulting program. VS Code is the editor used to create and manage source files.

1. What is C++?

C++ (pronounced “C plus plus”) is a compiled language for writing precise, high-performance instructions for the computer.

  • Why a language is needed: the CPU (Central Processing Unit), the processor that executes instructions, operates directly on machine code (binary instructions). Writing binary directly is impractical, so C++ provides a structured syntax that is translated into machine code by a compiler.
  • What C++ is used for: performance-critical software including operating systems, browsers, game engines, media tools, image editors, and machine-learning libraries such as PyTorch. It is selected where execution speed and control over resources are required.
  • Why learn it: performance and control. C++ provides direct management of memory (RAM, the short-term storage used during execution) and direct access to OS (Operating System — Windows, macOS, or Linux, the software that manages hardware and program execution) services, the GPU (graphics processor), networking, and audio hardware. This control is required for the shell, game, and inference projects built later in this course.
  • What C++ code is: a plain-text file with the extension .cpp. Example: hello.cpp. It can be opened in any text editor; this course uses VS Code for syntax highlighting and integrated compilation.
  • What a version such as C++17 means: C++ is defined by an ISO standard revised periodically. C++17 refers to the standard published in 2017 — stable and broadly supported. C++20 is the 2020 revision with additional features. This course uses C++17 for maximum compatibility.

2. Files, folders, and the .cpp extension

These are standard filesystem concepts, stated here for precision:

  • File: a named unit of stored data. The suffix after the final dot is the extension, which indicates the file type. Examples: birthday.jpg (image), notes.txt (plain text), song.wav (audio).
  • Folder (also called directory): a container for files and other folders. Example: Documents\MyCode\ on Windows or Documents/MyCode/ on macOS/Linux. The separator (\ or /) denotes nesting.
  • .cpp: the extension indicating a C++ source file. hello.cpp contains the source for the program named hello. The compiler uses this extension to identify the input language.
  • .exe (Windows): an executable file produced by compiling and linking source code. The .cpp file is the input source; the .exe file is the compiled output the OS executes. On macOS/Linux the output typically has no extension (for example, hello).
  • Path (lowercase; distinct from PATH — see section 6): the location of a file in the filesystem. Example: C:\Users\You\Documents\hello.cpp.
Setup step: create a folder named CppCourse inside Documents. Store all .cpp files for this course there. Note its full path; it is required when navigating in the terminal.

3. VS Code: code editor

VS Code (Visual Studio Code) is a free editor for writing and managing code. It provides:

  • Syntax highlighting and bracket matching for readability.
  • Error indicators and hover documentation for rapid correction.
  • An integrated terminal, so compilation commands can be run without leaving the editor.
  • Extensions: optional add-ons. Install C/C++ by Microsoft for C++ language support (highlighting, diagnostics). Code Runner is optional and adds a run button, but this course teaches direct terminal commands so the underlying process is explicit.
  • Visual Studio (without “Code”): a separate, larger Windows-only IDE. It includes its own compiler (cl.exe). It is a valid alternative, but this course uses VS Code with g++ so that commands are consistent across operating systems.

Install VS Code: download from https://code.visualstudio.com/ and run the installer. Then open VS Code → Extensions view (four-squares icon in the sidebar) → search C/C++ → Install the extension published by Microsoft.

4. Terminal and PowerShell: command-line interface

A terminal is a text interface for running commands. Instead of selecting icons, you enter a command line and press Enter to execute it.

  • Terminology: terminal, console, command line, and shell refer to the same concept. A terminal is a text interface for running commands. On Windows this is PowerShell or Command Prompt. On macOS it is Terminal. On Linux it is Terminal or bash. Syntax varies slightly; function is equivalent.
  • Command structure: a command names a program followed by arguments. Example: g++ hello.cpp -o hello invokes the compiler g++ to compile hello.cpp and write the output to hello.
  • Prompt: the input line where commands are entered, typically ending in >, $, or %. Example: PS C:\Users\You\Documents\CppCourse> indicates the current directory is CppCourse.
  • Current directory (working directory): the directory the terminal operates in. Commands resolve relative file names against it. If the file is in Documents\CppCourse but the terminal is in Desktop, the file will not be found. Use cd (change directory) to navigate.

How to open a terminal:

# Windows: press Start, type PowerShell, press Enter
#   (PowerShell window opens). Then navigate to your folder:
cd $HOME\Documents\CppCourse

# Mac: press Cmd+Space, type Terminal, press Enter. Then:
cd ~/Documents/CppCourse

# Linux: press Ctrl+Alt+T. Then:
cd ~/Documents/CppCourse

Essential commands:

pwd        # print working directory: shows the current directory path
  # (on PowerShell, pwd is an alias for Get-Location)
ls         # list directory contents: shows files in the current directory
  # (on PowerShell, ls is an alias; dir is the native equivalent)
cd Folder  # change directory: sets the current directory to Folder
cd ..      # move to the parent directory
g++ --version  # display the installed compiler version; confirms installation
Note: pwd, ls, and cd are read-only navigation commands. They list or change the viewed directory without modifying files. Compilation commands that create output files are explained in section 8.

5. g++, MinGW, and MSYS2

  • Compiler: A compiler translates C++ source code into machine code the CPU executes. It does this in three stages: preprocessing of directives, translation to object code, and linking with libraries. If the source contains syntax errors, compilation stops and reports an error indicating the location and cause.
  • g++: a widely used C++ compiler, part of the GCC (GNU Compiler Collection). Invoking g++ hello.cpp -o hello executes the compiler on the specified input. On macOS, g++ typically invokes clang++ (Apple’s compiler); the commands used in this course are compatible with both.
  • MinGW-w64 and MSYS2 (Windows): Windows does not include a C++ compiler by default. MinGW-w64 is a Windows port of GCC providing g++. MSYS2 is a package manager and environment for installing and updating MinGW-w64. In short: MSYS2 installs and maintains the toolchain; MinGW-w64 provides the compiler binaries; g++ is the compiler executable.
  • cl.exe (Visual Studio): Microsoft’s C++ compiler. It is functional but uses different command syntax (cl hello.cpp). This course uses g++ syntax for cross-platform consistency.
  • Debugger (gdb): a tool for pausing execution, inspecting variables, and stepping through code line by line. On Linux it is included with build-essential. It is introduced in Lesson 02.

6. PATH: definition and verification

PATH is an OS-level list of directories searched for executables. When a command name such as g++ is entered, the OS checks each directory in PATH in order and executes the first match. If no directory contains the program, the OS reports 'g++' is not recognized or command not found.

  • Configuration requirement: after installing MinGW, its binary directory (for example, C:\msys64\ucrt64\bin) must be included in PATH. The MSYS2 installer provides an option to add it; accept it. Without this entry, PowerShell cannot locate g++ even when it is installed.
  • PATH versus path: lowercase “path” denotes the location of a single file (C:\...\hello.cpp). Uppercase “PATH” denotes the OS-level search list. This course capitalizes the latter throughout.

How to check PATH and g++:

# Step 1: verify the compiler is resolvable
g++ --version
# Expected: version output such as g++ (Rev...) 13.2.0 or Apple clang version ...
# If the result is 'g++' is not recognized / command not found, PATH is misconfigured (see fix below)

# Step 2: inspect the directory list (optional)
# Windows PowerShell:
$env:Path -split ';'
# Mac / Linux:
echo $PATH | tr ':' '\n'

# Step 3: locate the g++ executable
# Windows PowerShell:
where.exe g++
# Mac / Linux:
which g++
Requirement: after modifying PATH or installing a compiler, close and reopen the terminal before testing. Existing terminal sessions retain the previous PATH value. Most “not recognized” errors are resolved by this step.

   # If missed: search Start for "Edit environment variables",

Option B — Visual Studio Community (larger download, integrated debugger): Download “Visual Studio Community” (distinct from VS Code), run the installer, and select the workload “Desktop development with C++”. This provides cl.exe and a debugger. To follow this course verbatim, also install VS Code with MinGW so that g++ commands apply directly.

Also install VS Code with the C/C++ by Microsoft extension (see section 3). Code Runner is optional.

Mac

macOS provides Apple’s compiler toolchain; it must be activated:

xcode-select --install

Verification (all systems): g++ --version should report a version such as g++ 13.x or clang 15.x. Version 9 or later is sufficient. If “not recognized / not found” is reported, recheck section 6: reopen the terminal, verify PATH, and repeat the installation step.

8. Hello, World — line by line

Create a file named hello.cpp inside CppCourse. In VS Code: File → Open Folder → select CppCourse → New File → save as hello.cpp (the extension must be .cpp, not .txt). Enter the following:

// hello.cpp -- my first program
#include <iostream>   // gives us std::cout for printing

int main() {          // every C++ program starts at main()
    std::cout << "Hello, world!\n";  // print text + newline
    return 0;         // 0 means "success" to the OS
}

Compile and run. In VS Code press Ctrl+` (backtick, left of the 1 key) to open the integrated terminal, then enter:

g++ -std=c++17 -Wall -Wextra hello.cpp -o hello
./hello        # on Windows instead: .\hello.exe

Compile command, token by token (this command is used throughout the course):

  • g++ — invokes the C++ compiler.
  • -std=c++17 — selects the language standard. -std specifies the standard; c++17 selects the 2017 revision.
  • -Wall -Wextra — enables standard and additional compiler warnings. -W denotes a warning category. These options surface potential errors during compilation.
  • hello.cpp — the input source file to compile.
  • -o hello — sets the output file name. -o denotes output. On Windows the output is hello.exe.
  • ./hello (macOS/Linux) — executes the program in the current directory. . denotes the current directory; / is the path separator.
  • .\hello.exe (Windows) — the equivalent invocation on Windows, using \ as the separator and .exe as the executable extension.

Source file, line by line:

  • // hello.cpp -- my first program — a comment. Text following // is ignored by the compiler and serves as documentation.
  • #include <iostream> — a preprocessor directive that includes the standard header iostream. #include requests inclusion; angle brackets indicate the standard library location. iostream provides input/output facilities, including std::cout. Without it, std::cout is undefined.
  • Blank line — has no effect; included for readability.
  • int main() { — defines the program entry point. main is a function (a named block of code) that the OS calls first. () indicates no parameters in this example. int specifies that main returns an integer exit code. { opens the function body.
  • std::cout << "Hello, world!\n"; — outputs text. std is the standard library namespace; :: is the scope-resolution operator; cout is the standard character-output stream. << is the insertion operator directing data to the stream. "..." is a string literal. \n is the newline escape sequence. ; terminates the statement — every statement requires one.
  • return 0; — returns the exit code to the OS. 0 indicates successful execution; nonzero values indicate an error condition. Inspect it with echo $? (macOS/Linux) or echo $LASTEXITCODE (PowerShell) immediately after execution.
  • } — closes the body of main. Each opening brace requires a matching closing brace.
Expected result: the terminal displays Hello, world! followed by a new prompt. If output differs, refer to sections 9 and 10 for the build process and error reference.

9. What happens when you compile? (preprocessor → compiler → linker)

A single g++ ... invocation performs three sequential stages:

hello.cpp -> [preprocessor] -> [compiler] -> hello.o -> [linker + stdlib] -> hello.exe
  #include expanded   C++ -> assembly -> object code    objects joined into program
  • Stage 1 — Preprocessor. Processes directives beginning with #. For #include <iostream>, it inserts the referenced header content into the translation unit, producing a complete source for compilation.
  • Stage 2 — Compiler. Translates the preprocessed C++ into assembly (low-level CPU mnemonics such as mov and call), then into object code (hello.o — machine code that is not yet executable because references to library functions remain unresolved).
  • Stage 3 — Linker. Combines object files with the standard library (stdlib — pre-compiled implementations of facilities such as output) into a single executable (hello.exe or hello).
  • Runtime role of the OS: when ./hello is executed, the OS loads the program into memory (RAM), provides access to output facilities, invokes main(), captures the exit code, and releases resources on termination.

To observe each stage directly (optional):

g++ -E hello.cpp -o hello.i   # preprocessed output (large: source plus expanded headers; inspect hello.i)
g++ -S hello.cpp -o hello.s   # assembly output: low-level CPU instructions in hello.s
g++ -v hello.cpp -o hello     # verbose mode: displays each stage and searched paths
Working practice: A compiler translates C++ source code into machine code the CPU executes. It does this in three stages: preprocessing, compilation, and linking. A reported error identifies the file and line to correct. Reviewing errors systematically is standard practice.

10. Common errors and corrections

DiagnosticMeaningCorrection
'g++' is not recognized / command not foundThe OS searched each directory in PATH and found no program named g++. The compiler is either not installed or its directory is not in PATH, or the terminal session predates the PATH update.Open a new terminal and rerun g++ --version. If the error persists, verify the MinGW binary directory (for example, C:\msys64\ucrt64\bin) is listed in PATH (section 6) and repeat the installation step.
expected ';' before ... / expected ';'A statement is missing its terminating semicolon.Locate the reported line number and append ;. Example: std::cout << "hi" → std::cout << "hi";
undefined reference to 'main'The linker found no entry point named main. The function is typically misspelled (Main, mian) or has an incorrect signature.Verify the exact spelling int main() with lowercase m. Confirm the file is saved and the correct file name is passed to g++.
'cout' was not declared / 'cout' was not declared in this scopecout was used without the required header or qualified name.Add #include <iostream> at the top and use the qualified name std::cout. The prefix std:: refers to the standard library namespace.
No such file or directory: hello.cppThe working directory does not contain hello.cpp. The terminal is in a different directory than the source file.Run pwd and ls to confirm location. Use cd to navigate to the source directory (section 4). In VS Code, open the project folder first, then open the integrated terminal.
cannot open output file hello.exe / Permission deniedThe output file is locked, typically because a previous instance is still running, or antivirus software has restricted access.Terminate any running instance of the program. Check antivirus quarantine if applicable. Then repeat the g++ command.
stray '\...' / expected primary-expressionThe source contains an invalid character, commonly curly quotation marks “ ” instead of straight quotes " ".Re-enter quotation marks and semicolons directly in VS Code. Avoid copying code from formatted documents without correcting punctuation.
fatal error: iostream: No such fileThe preprocessor could not locate the standard headers. The compiler installation is incomplete.Repeat the installation in section 7. On Linux, confirm build-essential completed. On Windows, confirm the package mingw-w64-ucrt-x86_64-gcc is installed.

Exercises (5 minutes each)

  1. Print your name and age on two lines. Use two std::cout statements, each with \n and a terminating ;. Compile and run.
  2. Observe the exit code. Change return 0; to return 3;, recompile, run, then immediately enter echo $LASTEXITCODE (PowerShell) or echo $? (macOS/Linux). The value 3 should be displayed. Restore return 0; afterward.
  3. Practice error diagnosis: remove one ;, recompile, and note the reported line number and message. Restore the semicolon and recompile to confirm the error is resolved.
  4. Enable strict warnings. Compile with g++ -std=c++17 -Wall -Wextra hello.cpp -o hello and address any reported warnings. Warning-free compilation is standard professional practice.

VS Code tips

  • Open the folder, not only the file. Use File → Open Folder → select CppCourse. Opening only hello.cpp may leave the integrated terminal in a different directory, causing “No such file” errors.
  • Use the integrated terminal: press Ctrl+` to open a terminal already set to the open folder.
  • Verify the file extension is .cpp. If Windows hides extensions, enable View → Show → File name extensions in Explorer to distinguish hello.cpp from hello.cpp.txt. Only the former is recognized as C++ source.
