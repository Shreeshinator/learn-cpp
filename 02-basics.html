1. Variables and fundamental types

A variable is a named storage location with an associated type. The type determines the size, the set of representable values, and the permitted operations. C++ is statically typed: each variable’s type is declared and checked at compile time.

int x = 10;
char c = 'A';
float f = 3.14f; // f suffix, otherwise 3.14 is a double
double d = 3.14;
bool b = true;
Line by line
• int x = 10; — declares an integer variable x initialized to 10. Typically 4 bytes.
• char c = 'A'; — declares a 1-byte character variable. Single quotes denote a character literal. The value is the character encoding (65 in ASCII/UTF-8 for 'A').
• float f = 3.14f; — declares a 4-byte floating-point variable. The f suffix specifies float; without it, 3.14 has type double.
• double d = 3.14; — declares an 8-byte floating-point variable with higher precision. The default choice for fractional values.
• bool b = true; — declares a Boolean variable holding true or false. Introduced in C++ (C historically used int 0/1).

Type sizes: char is always 1 byte. Other sizes are implementation-defined — int is commonly 4 bytes, but the standard specifies only minimum ranges. When an exact width is required (file formats, network protocols), use fixed-width types such as int32_t and uint8_t from <cstdint>.

const, constexpr, auto

const int MAX = 100;        // constant: value cannot be modified. Prefer over #define
constexpr int SIZE = 10*10; // constant evaluated at compile time (C++11+)
auto y = 42;      // C++11: type deduced by the compiler as int
auto s = std::string("hi"); // deduced as std::string

#define MAX 100 performs untyped text substitution. const and constexpr are typed and respect scope. Prefer const and constexpr.

Storage duration

int global = 5; // global/static storage: data segment, persists for the program lifetime

int main(){
  int local = 1; // automatic storage (stack): released when the function returns
  static int calls = 0; // static storage inside a function: initialized once, persists across calls
  calls++;
  int* p = new int(10); // dynamic storage (heap): persists until explicitly released
  delete p;
}

2. Typecasting — converting between types

A cast is an explicit conversion from one type to another, for example from double to int. C permits (int)3.7, which performs the conversion without restriction. C++ provides four named casts that are type-checked, explicit, and searchable.

double pi = 3.7;
int a = (int)pi;                 // C-style: permitted, but unchecked and difficult to locate

int b = static_cast<int>(pi);    // standard numerical conversion, checked at compile time
// reinterpret_cast: low-level reinterpretation of the bit pattern, e.g. address manipulation
int* p = reinterpret_cast<int*>(0x100);
// const_cast: removes const qualification only
// dynamic_cast: checked downcast within an inheritance hierarchy, requires a polymorphic base, verified at runtime
Selection criteria
• Standard numeric or pointer-to-base conversion → static_cast.
• Low-level address or bit-pattern reinterpretation → reinterpret_cast (infrequent, implementation-dependent).
• Removal of const to interoperate with a non-const API → const_cast (infrequent).
• Conversion from Base* to Derived* with runtime verification → dynamic_cast (returns nullptr on failure for pointer types).
Frequent casting indicates the design should be revised to reduce type mismatches.
// Implicit promotion: the compiler widens automatically
int i = 5;
float f2 = i + 2.5f; // int + float -> float
char ch = 'A';
int code = ch;       // char -> int (65). This is integral promotion.
int x2 = 7 / 2;      // 3: both operands are int, so integer division applies. Use 7.0/2 for 3.5

3. Enums — named constant sets

An enumeration defines a set of named integer constants, avoiding unexplained literal values:

enum Color { RED, GREEN = 5, BLUE }; // RED=0, GREEN=5, BLUE=6 (continues sequentially from 5)

A plain enum exposes its enumerators in the enclosing scope and converts implicitly to int. C++ provides scoped enumerations that prevent both:

enum class Color { Red, Green, Blue }; // scoped, strongly typed
Color c = Color::Red;                  // qualification required
// int v = c; // ERROR: no implicit conversion — this restriction is intentional
int v = static_cast<int>(c);            // explicit conversion where required

Rule: use enum class for all new code.

4. typedef / using — type aliases

typedef unsigned int uint;              // C style
typedef struct { int x, y; } Point;      // C style struct alias

using uint = unsigned int;              // C++ style — prefer this
using Matrix = std::vector<std::vector<int>>; // Matrix is an alias for a 2D vector

using provides the functionality of typedef and integrates consistently with templates. Prefer using.

5. Pointers and references

A pointer is a variable that stores a memory address. A reference is an alias — an alternative name for an existing variable.

int x = 10;
int* p = &x;  // & = address-of operator. p stores the address of x
int v = *p;   // * = dereference operator. v receives the value at that address (10)
p = nullptr;  // null state: points to no object. Use nullptr; avoid NULL (defined as 0)
* and & depend on context
• In a declaration: int* p declares a pointer; int& r declares a reference.
• In an expression: *p dereferences a pointer; &x takes the address of x.
Declarations are read right-to-left: int* p = “p is a pointer to int”.
int& r = x;   // reference: alias for x. Must be initialized, cannot be null, cannot be reseated
r = 20;       // assignment through r modifies x; both names refer to the same storage

int arr[3] = {1, 2, 3};
*(arr + 1) == arr[1]; // true. arr converts to a pointer to its first element.
                      // Adding 1 advances by sizeof(int), not by one byte. This is pointer arithmetic.

// Dynamic allocation:
int* q = new int(5); // allocates one int on the heap
delete q;            // must be released; otherwise the allocation is leaked
int* a = new int[10]; // array allocation on the heap
delete[] a;           // array form required for arrays
Common pointer errors: (1) Dangling pointer — accessing storage after delete. (2) Memory leak — omitting delete for heap storage. (3) Double-free — calling delete twice on the same address. Mitigation: use smart pointers (Lesson 04).
#include <memory>
std::unique_ptr<int> u = std::make_unique<int>(5); // sole ownership; released automatically
// *u accesses the value. u cannot be copied, only moved.

// Pointer to pointer and function pointers (common in C interfaces):
int** pp = &p;              // pointer to a pointer
void foo(int n) {}
void (*fp)(int) = &foo;     // fp is a pointer to function foo
fp(42);                     // invokes foo(42)

6. Functions

int add(int a, int b); // declaration (prototype): states the signature; definition follows
int add(int a, int b) { return a + b; } // definition: provides the implementation

Argument-passing methods

void f1(int x) { x = 99; }              // by value: operates on a copy; caller is unaffected
void f2(int* x) { *x = 99; }            // by pointer (C style): permits null; validate before dereference
void f3(int& x) { x = 99; }             // by reference (C++ style): modifies caller; never null
void f4(const std::string& s);          // const reference: avoids copying, read-only. Standard for strings and vectors

void greet(int a = 10); // default argument (C++): greet() is equivalent to greet(10)

// Variadic function (C style, uncommon): sum(3, 1,2,3)
#include <cstdarg>
int sum(int n, ...); // for a type-safe alternative, see variadic templates in Lesson 07
// Overloading (C++ only; C does not support overloading):
int add(int a, int b) { return a+b; }
double add(double a, double b) { return a+b; } // same name with distinct parameter types is permitted

inline int sq(int x) { return x*x; } // suggestion to expand at the call site; the compiler determines application

7. struct / union — aggregate types

struct Point { int x; int y; }; // C: aggregate of public data members
struct Point p1 = {1, 2};

In C++, struct and class differ only in default member access (struct defaults to public; class defaults to private). C++ structs may include member functions, constructors, and inheritance:

struct Point {
  int x, y;
  Point(int x, int y): x(x), y(y) {}
  void move(int dx, int dy){ x+=dx; y+=dy; }
};
union Data { int i; float f; }; // i and f occupy the same storage. Size equals the largest member.
Data d; d.i = 42;               // reading d.f would reinterpret the same bytes as float
// Applicable to storage-constrained layouts and hardware registers. Prefer std::variant in modern C++.

8. Standard I/O and File I/O

C style (retained for compatibility; common in existing C code and embedded systems)

#include <cstdio>
int x = 42; char c = 'A'; const char* str = "hi";
printf("%d %s %c\n", x, str, c);
scanf("%d", &x); // address-of operator required to store the result

FILE* fp = fopen("a.txt", "r"); // modes: r = read, w = write (truncate), a = append, r+ / w+ = read and write
if(fp){
  fprintf(fp, "hi %d", x);
  fscanf(fp, "%d", &x);
  fclose(fp);
}
SpecifierCorresponding type
%dint
%ffloat / double
%cchar
%sC-style string
%ppointer
%xunsigned int, hexadecimal format

C++ style (recommended)

#include <iostream>
#include <fstream>
#include <string>
int x; std::string str;
std::cout << x << std::endl; // endl inserts a newline and flushes the stream (prefer '\n' in loops for performance)
std::cin >> x;                    // formatted extraction; skips leading whitespace
std::getline(std::cin, str);     // reads a complete line including spaces

std::ifstream in("a.txt");   // input file stream for reading
std::ofstream out("b.txt");  // output file stream for writing (truncates existing content)
std::string line;
while(std::getline(in, line)) out << line << '\n';
Input interaction: after std::cin >> x, the trailing newline remains in the buffer, so a subsequent getline returns an empty string. Insert std::cin.ignore(1000,'\n'); between formatted extraction and line-based input.

9. Storage and type qualifiers: static, const, friend, virtual

const int* p1;       // pointer to const: *p1 cannot be modified through p1 (p1 itself can be reassigned)
int* const p2 = &x;  // const pointer: p2 cannot be reassigned (*p2 can be modified)
int f() const;       // const member function: does not modify the object state
constexpr int N = 64; // compile-time constant expression
// static has three distinct meanings depending on context:
void counter(){
  static int n = 0; // 1. local static: initialized once, retains its value across calls
  n++;
}
static int helper(){} // 2. internal linkage at file scope (C). In C++ prefer an anonymous namespace.
class A {
  static int count; // 3. static data member: single instance shared by all objects of the class
};
extern int g;   // declaration of a variable defined in another translation unit
volatile int flag; // indicates the value may change externally; prevents caching optimizations

class A {
  friend class B;     // grants class B access to private members of A
  friend void f(A&);  // grants function f access to private members of A
private: int x;
};

virtual void draw() = 0; // pure virtual function: derived classes must override; makes the class abstract

10. OOP concepts (preview — full Lesson 03)

#include <iostream>
#include <string>
class Animal {
private: int age = 0;
protected: std::string name; // accessible to derived classes, not to external code
public:
  Animal(std::string n): name(n) {}
  virtual void speak() { std::cout << name << "\n"; } // virtual: dispatch to the derived override
  virtual ~Animal() {} // virtual destructor required when a base class has virtual functions
};
class Dog : public Animal { // public inheritance (protected and private inheritance also exist)
public:
  Dog(): Animal("dog") {}
  void speak() override { std::cout << "woof\n"; } // override: replaces the base implementation
};
The four principles
1. Encapsulation: restrict direct access (private) and expose a controlled interface (public).
2. Inheritance: derive classes from a base (class Dog : public Animal). Multiple inheritance (class D : public B1, public B2) is permitted but can introduce ambiguity when bases share an ancestor (the diamond hierarchy) — address with virtual inheritance or prefer composition.
3. Polymorphism: compile-time (function overloading, templates) versus runtime (overridden virtual functions invoked through a Base*).
4. Abstraction: define behavior through pure-virtual interfaces without exposing implementation.

Object lifetime: default, parameterized, copy (A(const A&)), and move (A(A&&)) constructors, plus member initializer lists. Rule of 3/5: if a destructor, copy, or move operation is explicitly defined, define all applicable operations (alternatively, apply RAII so no manual definition is needed). this is a pointer to the current object. An explicit constructor prevents unintended implicit conversions. Operators (+, ==) may be overloaded for user-defined types.

11. STL, vectors & templates (preview — full Lesson 05)

#include <vector>
#include <algorithm>
#include <string>
int main(){
  std::vector<int> v = {3, 1, 2};
  v.push_back(4);   // amortized O(1); capacity is expanded geometrically when exhausted
  v.pop_back();
  v.size(); v[0]; v.at(0); // at() performs bounds checking; operator[] does not
  for(int x : v) std::cout << x;
  sort(v.begin(), v.end()); // iterators delimit the range from begin to end
}

// Templates provide the mechanism behind the STL. A single definition supports multiple types:
template<typename T>
T myMax(T a, T b){ return a > b ? a : b; }

double m2 = myMax(2.5, 1.1); // T deduced as double

12. Control flow: if, switch, loops

int marks; std::cin >> marks;
if(marks >= 90) std::cout << "A\n";
else if(marks >= 75) std::cout << "B\n";
else std::cout << "Keep practicing\n";

char op = '+';
switch(op){
  case '+': std::cout << "add\n"; break; // break prevents fall-through to the next case
  case '-': std::cout << "sub\n"; break;
  default: std::cout << "?\n";
}

for(int i = 1; i <= 5; i++) std::cout << i << " ";
int n = 1;
while(n <= 5){ std::cout << n << " "; n++; }

Exercises

  1. Types: print sizeof(char,int,float,double,bool). Explain why 7/2==3.
  2. Casts: convert 3.99 with static_cast<int>; attempt assignment from enum class to int (observe the error), then correct it with an explicit cast.
  3. Pointers: implement void swap(int&,int&); then verify *(arr+2)==arr[2].
  4. Allocation: allocate new int[5], output the values, then release with delete[]. Recompile with -fsanitize=address to verify memory correctness.
  5. Functions: overload add(int,int) and add(string,string).
  6. I/O: implement the same program twice: once with printf/scanf and once with cin/cout/getline. Handle the ignore() requirement between formatted and line input.
  7. Files: write 5 names to a file, then read them back with line numbers.
  8. Calculator + FizzBuzz (standard introductory exercises).
