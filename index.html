1. What this site is

This site is a self-contained C++ course distributed as local files on your computer.

  • A file is a named unit of storage on disk, identified by a name and extension. Files in this course use the extension .cpp to indicate C++ source code. Example: hello.cpp.
  • C++ (pronounced “C plus plus”) is a compiled, general-purpose programming language designed for performance and direct control over system resources. The CPU executes only machine code (binary instructions). C++ provides a structured, human-readable syntax that is translated into machine code before execution.
  • A compiler translates C++ source code into machine code the CPU executes. It does this in three stages: preprocessing, compilation to object code, and linking. This course uses g++ (introduced in Lesson 01).
  • A terminal (also called console or command line; PowerShell or Command Prompt on Windows) is a text interface for running commands. You enter a command and the operating system executes it. It is used here to invoke the compiler and run programs.
  • VS Code (Visual Studio Code) is a free code editor. It provides syntax highlighting, bracket matching, error indicators, and an integrated terminal for compiling and running code without switching windows.
  • An .exe file (on Windows) is a compiled executable. A .cpp file contains source code; after compilation and linking, the result is an executable that the operating system can run directly.

6. How C++ fits together

The complete build and execution sequence is summarized below. Each stage is examined in Lesson 01:

your .cpp file  (human-readable source, e.g. hello.cpp)
   -> preprocessor (#include ...)  -- resolves directives and expands includes
   -> compiler (C++ -> object code) -- translates to CPU instructions
   -> linker (object + libraries -> .exe) -- combines object files with libraries
   -> OS runs it, manages memory / files / network / audio / GPU

STL gives you ready-made tools: vector, string, map, algorithm
OOP lets you model big programs: classes, inheritance
Pointers + RAII let you control memory safely
Threads + sockets + system calls let you talk to OS & network
OpenGL / SFML / miniaudio let you talk to GPU & sound card
  • Preprocessor processes directives beginning with #, such as #include, before compilation begins.
  • Libraries are pre-compiled, reusable code modules that provide common functionality without reimplementation.
  • OS (Operating System) — Windows, macOS, or Linux — loads the executable into memory, schedules execution, and provides access to files, networking, audio, and display resources.

7. Study plan

  1. Complete lessons in order. Later topics (pointers, object-oriented design, projects) depend directly on earlier material.
  2. Enter each example manually. Compile each file with:
    g++ -std=c++17 -Wall -Wextra file.cpp -o app
    This invokes g++ using the C++17 standard, enables all common and extra warnings (-Wall -Wextra), compiles file.cpp, and writes the executable to app. A full breakdown is in Lesson 01.
  3. Complete the exercises at the end of each page. They are designed to take approximately 5 minutes each.
  4. When an error occurs: read the message, note the reported line number, consult the error table in Lesson 01, change one item at a time, and recompile. Compiler errors are diagnostic output indicating what to correct.
  5. After Lesson 07, complete one project fully before starting another. A completed project is more valuable than several incomplete ones.

8. Quick FAQ

  • Do I need math? Basic arithmetic is sufficient until the AI lesson, where each required formula is explained.
  • How long will it take? Lesson 01 takes approximately 45 minutes. Subsequent lessons take approximately one hour each if all examples are entered and compiled. At a steady pace, the project section is reachable in 5–8 weeks.
  • Mac / Linux users? All material applies. Lesson 01 lists the specific commands for each system. Executable invocation differs slightly (./app on macOS/Linux versus .\app.exe on Windows).
  • What if English isn’t my first language? C++ keywords are limited in number (if, for, return) and each is defined as vocabulary. Code comments may be written in any language.
