Build an AI inference engine from scratch (no libraries)

Goal: implement forward inference for a multilayer perceptron using only the standard library (std::vector and scalar arithmetic). This project covers AI, inference vs training, neuron, weight, bias, ReLU, softmax, argmax, matrix, forward pass, and MLP.

Overview: Training optimizes parameters on large datasets; inference applies trained weights: z = Wx + b, ReLU, softmax. This engine implements inference in C++ for deployment without Python dependencies: load parameters, evaluate the forward pass, select the maximum-probability class.

1. AI: inference vs training

  • AI (model evaluation) in this context = mapping numeric inputs to numeric outputs via learned parameters. Example: input vector [0.9, 0.1, 0.8, 0.2] → probability vector [0.7, 0.2, 0.1]. Behavior is determined by parameter values, not explicit rules.
  • Training = numerical optimization of parameters. Performed in Python (PyTorch/scikit-learn) by minimizing prediction error over labeled datasets (gradient descent = iterative error minimization). Computationally intensive, executed once.
  • Inference = application of fixed parameters to new inputs. Consists of matrix multiplication, addition, and elementwise nonlinearities. Deterministic, portable, executed repeatedly. This lesson implements inference exclusively.
  • Model = parameter set plus evaluation procedure. MLP (Multi-Layer Perceptron) = feedforward architecture with sequential fully-connected layers. This implementation: 4 → 8 → 3.
  • Constraint: no external dependencies (torch, Eigen excluded). Only vector/iostream/cmath/algorithm for containers, output, exponentials, and reductions.
Distinction: training determines parameter values; inference evaluates the parameterized function. The same inference code handles arbitrary dimensions — 4 inputs or 784-pixel MNIST vectors — with only parameter dimensions changing.

2. Neuron: weighted sum and bias

Definition: a neuron computes z = sum(w[i]*x[i]) + b, where x = inputs, w = weights, b = bias. Weight = per-input coefficient (positive amplifies, negative inverts). Bias = additive offset independent of inputs.

Numerical verification (evaluate manually):

x = [1, 2, 3], w = [0.5, -1.0, 0.2], b = 0.5
sum = 0.5*1 + (-1.0)*2 + 0.2*3 + 0.5
    = 0.5   + (-2.0)   + 0.6   + 0.5
    = -0.4
neuron output (pre-activation) = -0.4
Interpretation: each input is scaled by its weight and accumulated with the bias. Large positive values indicate strong activation; large negative values indicate suppression. A layer = multiple neurons evaluated on identical inputs, each with independent weights/bias. The hidden layer contains 8 neurons; the output layer contains 3.

3. ReLU, softmax, and argmax

Raw scores require normalization before interpretation. Three standard transformations:

  • ReLU (Rectified Linear Unit) = max(0, x). Negative values map to zero; non-negative values are unchanged. Introduces nonlinearity, enabling multilayer networks to represent non-linear functions. Example: [-0.4, 2.1, 0.0] → [0, 2.1, 0].
  • Softmax = converts logits to a probability distribution summing to 1: softmax[i] = exp(z[i]) / sum(exp(z)). exp = exponential function (ensures positivity, accentuates maxima). Normalization yields class probabilities.
  • Argmax = index of the maximum element. For [0.7, 0.2, 0.1], argmax = 0. This index is the predicted class.
ReLU example:
  in  = [-1.0, 0.5, 0.0]
  out = [ 0.0, 0.5, 0.0]

Softmax example with z = [2.0, 1.0, 0.1]:
  exp(z) = [7.39, 2.72, 1.11]
  sum = 11.22
  probs = [0.66, 0.24, 0.10]    # sums to 1.0

Argmax example:
  probs = [0.66, 0.24, 0.10] -> argmax = 0
Numerical stability: exp(1000) overflows. Subtracting the maximum prior to exponentiation (exp(z[i]-max)) preserves the result (normalization cancels the constant) while bounding intermediate values. The implementation below applies this standard technique.

4. Matrix engine: matVec

A matrix (Mat) = weight table with rows = layer neurons, columns = inputs. A vector (Vec) = one-dimensional value list. matVec evaluates one fully-connected layer: each row computes z = Wx + b.

// ai.cpp -- g++ -std=c++17 -O2 ai.cpp -o ai
#include <vector>
#include <iostream>
#include <cmath>
#include <algorithm>
#include <string>
#include <fstream>
#include <chrono>
using Vec = std::vector<float>;
using Mat = std::vector<Vec>;  // rows x cols

Vec matVec(const Mat& W, const Vec& x, const Vec& b) {
    Vec y(W.size(), 0);
    for (size_t i = 0; i < W.size(); i++) {
        float s = b[i];
        for (size_t j = 0; j < x.size(); j++) s += W[i][j] * x[j];
        y[i] = s;
    }
    return y;
}
void relu(Vec& v) {
    for (auto& x : v) x = std::max(0.f, x);
}
Vec softmax(Vec z) {
    float m = *std::max_element(z.begin(), z.end());
    float sum = 0;
    for (auto& x : z) { x = std::exp(x - m); sum += x; }
    for (auto& x : z) x /= sum;
    return z;
}
int argmax(const Vec& v) {
    return (int)(std::max_element(v.begin(), v.end()) - v.begin());
}
Type aliases: using Vec = vector<float> defines a single-precision decimal list. using Mat = vector<Vec> defines a row-major table. float (32-bit) is standard for inference (reduced memory vs double). Additional headers (string/fstream/chrono) support file loading and benchmarking below.
matVec specification:
Vec matVec(const Mat& W, const Vec& x, const Vec& b) — W = weight matrix, x = input vector, b = bias vector (one per row). const & = pass by constant reference (no copy).
Vec y(W.size(), 0); — result vector with one entry per row (neuron).
for (i...) float s = b[i]; — initializes accumulator with the bias term.
for (j...) s += W[i][j]*x[j]; — accumulates weighted inputs. W[i][j] = row i, column j.
y[i]=s; — stores the pre-activation score. return y; returns the layer output.
Activation utilities:
relu: in-place elementwise maximum with zero (auto& mutates the argument directly).
softmax: accepts z by value (operates on a copy). Computes maximum m, applies exp(x-m) with summation, then divides by the sum to produce probabilities.
argmax: max_element returns an iterator to the maximum; subtracting begin() yields the index.

5. Multilayer perceptron: 4 → 8 → 3 forward pass

Forward pass = single inference evaluation: input → hidden pre-activations → ReLU → output logits → softmax → class selection. Parameters below are illustrative fixed values for mechanical verification (not trained).

struct MLP {
    Mat W1 = {{.2,.5,-.3,.1},{.4,-.1,.6,.2},{-.5,.3,.1,.4},{.1,.1,.1,.1},
              {.3,-.2,.5,-.4},{.6,.1,-.1,.2},{-.2,-.3,.4,.5},{.1,.6,-.5,.3}};
    Vec b1 = {0,0,0,0,0,0,0,0};
    Mat W2 = {{.5,-.2,.3,.1,.4,-.1,.2,.3},{-.3,.4,.1,.5,-.2,.3,.1,-.4},{.1,.2,-.4,.3,.1,.5,-.3,.2}};
    Vec b2 = {0,0,0};
    Vec forward(Vec x) {
        Vec h = matVec(W1, x, b1);
        relu(h);
        Vec z = matVec(W2, h, b2);
        return softmax(z);
    }
};
int main() {
    MLP net;
    Vec sample = {0.9, 0.1, 0.8, 0.2};  // example feature vector
    Vec probs = net.forward(sample);
    std::cout << "probs: ";
    for (float p : probs) std::cout << p << " ";
    std::cout << "\n predicted class: " << argmax(probs) << "\n";
    return 0;
}
Line by line:
struct MLP { ... }; — aggregate containing parameters and evaluation method.
Mat W1 (8×4) — hidden-layer weights: 8 neurons × 4 inputs. Vec b1 (8 zeros) — hidden biases.
Mat W2 (3×8) — output-layer weights: 3 classes × 8 hidden activations. Vec b2 (3 zeros) — output biases.
Vec forward(Vec x) — matVec(W1,x,b1) → 8 hidden scores → relu(h) → matVec(W2,h,b2) → 3 logits → softmax → probabilities.
main: instantiates net, defines input vector sample, evaluates forward, prints probabilities and argmax (predicted class 0/1/2). Modifying sample and re-executing demonstrates input-dependent classification.

7. Loading trained weights

Illustrative parameters validate mechanics. Production parameters originate from Python training and transfer via text serialization. The forward procedure is unchanged; only matrix dimensions increase (e.g. MNIST: 784 → 128 → 10).

# Python: train model, then serialize parameters as text:
# import numpy as np
# np.savetxt("W1.txt", W1)   # one row per line, space-separated
# np.savetxt("b1.txt", b1)
# np.savetxt("W2.txt", W2)
# np.savetxt("b2.txt", b2)
Python stage: savetxt writes numeric arrays as whitespace-delimited text, one row per line, producing W1.txt etc.
// C++: load serialized parameters (add to ai.cpp)
Vec loadVec(const std::string& path) {
    Vec v;
    float x;
    std::ifstream f(path);
    while (f >> x) v.push_back(x);
    return v;
}
Mat loadMat(const std::string& path, int rows, int cols) {
    Mat m(rows, Vec(cols));
    std::ifstream f(path);
    for (int i = 0; i < rows; i++)
        for (int j = 0; j < cols; j++) f >> m[i][j];
    return m;
}
// Then in main():
//   MLP net;
//   net.W1 = loadMat("W1.txt", 128, 784);
//   net.b1 = loadVec("b1.txt");
//   ... identical forward() on a 784-element input
C++ stage: loadVec opens the file (ifstream = input file stream) and extracts decimals with >> until exhaustion. loadMat preallocates a rows×cols matrix and fills it row-major via nested loops (outer = rows, inner = columns). After assignment, forward() executes unchanged: for MNIST, input = 784 grayscale values (28×28 flattened), output = 10 probabilities (digits 0–9), argmax = predicted digit.

8. Benchmarking

// Measure average inference latency:
auto t0 = std::chrono::high_resolution_clock::now();
for (int k = 0; k < 10000; k++) net.forward(sample);
auto t1 = std::chrono::high-resolution_clock::now();
double ms = std::chrono::duration<double, std::milli>(t1 - t0).count() / 10000.0;
std::cout << "avg ms per forward: " << ms << "\n";
Procedure: high_resolution_clock::now() captures timestamps. Executing forward 10000 times amortizes timer resolution; dividing by 10000 yields mean latency in milliseconds. chrono = C++ time facility. Compare -O2 vs unoptimized vs -O2 -march=native to quantify compiler optimization. Further directions: parallelize independent row computations with std::thread; quantize to int8 for reduced memory and increased throughput at minor precision cost.

9. AI microservice integration

The Lesson 08 TCP server combined with this inference engine forms an AI microservice (network-accessible prediction service).

Client (Python or C++) sends:  "0.9 0.1 0.8 0.2\n"
Server (Lesson 08 networking + this lesson):
  1. receive line -> parse to floats
  2. probs = net.forward(input)
  3. answer = argmax(probs)
  4. send: "class 0 (0.45 0.25 0.30)\n"
Handle successive clients in a loop.
Deployment rationale: resource-constrained clients transmit feature vectors to a C++ server (no Python runtime required) and receive predictions. Required components are now complete: transport (Lesson 08) + inference (this lesson). Integration produces a portfolio-grade C++ inference service.
