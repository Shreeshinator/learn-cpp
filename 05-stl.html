Lesson 05 · Standard Library

STL: vector, string, map, set & algorithms

This lesson covers the Standard Template Library facilities used in daily C++ practice: containers (vector, string, map, set), iterators, and algorithms (sort, find, transform). Each facility is defined precisely, with complete examples and line-by-line explanations.

In this lesson:

  2. Why vector replaces manual dynamic arrays
  3. vector — interface and semantics
  4. string vs char[]
  5. map vs unordered_map and set

1. Libraries, the STL, and templates

Definition — library
A collection of tested declarations and definitions made available via #include. Example: #include <vector> provides the dynamic-array container.
Definition — STL (Standard Template Library)
The standardized component of the C++ standard library comprising containers (objects storing sequences or associative data: vector, map, set), iterators (objects designating positions within containers), and algorithms (function templates such as sort and find operating on iterator ranges).
Definition — template
A parameterized definition from which the compiler generates type-specific versions. vector<T> is a class template: vector<int> denotes a sequence of integers; vector<std::string> denotes a sequence of strings. The argument in <...> specifies the element type: vector<int> reads "vector of int."

2. Why vector replaces manual dynamic arrays

Manual management with new int[N] requires explicit reallocation, size tracking, and lifetime control:

Manual array requirementvector provision
Fixed capacity must be estimated; growth requires allocating a larger array, copying elements, and releasing the original.Automatic growth via push_back, typically by doubling capacity (amortized constant time).
size and capacity must be tracked explicitly; indexing errors produce out-of-bounds access.Maintains both internally. size() returns the element count; capacity() returns allocated storage.
Copying a raw pointer produces aliased ownership and double release.Implements correct copy, move, and destruction semantics (Rule of 0).
Unchecked indexing (arr[i]) has undefined behavior when out of range.at(i) performs bounds checking and throws std::out_of_range.
Guideline: use vector as the default sequential container. Select an alternative (map, set, deque) only when its specified complexity or ordering properties are required.

3. std::vector — interface and semantics

Definition — vector
A dynamically resizable array storing elements in contiguous memory, which provides cache-efficient sequential access. std:: designates the standard library namespace. std::vector<int> v = {10,20,30}; defines a vector of integers containing three elements.
Definition — size_t
An unsigned integer type used for sizes and indices. v.size() returns size_t; loop indices should use size_t or auto to match.
#include <vector>
#include <iostream>
int main(){
    std::vector<int> v = {10,20,30};
    v.push_back(40);
    v.pop_back();
    std::cout << v.size() << " " << v[0] << " " << v.at(1) << "\n"; // prints: 3 10 20
    for(int x: v) std::cout << x << " ";
    for(size_t i=0;i<v.size();i++) std::cout << v[i] << " ";
    std::vector<std::vector<int>> grid(3, std::vector<int>(3,0)); // 3x3 zero-initialized
}

Member functions and syntax:

ExpressionDefinitionComplexity / notes
vector<int> v = {10,20,30};Constructs a vector containing the listed elements. size() is 3.Linear in element count.
push_back(40)Appends 40 after the last element, reallocating (typically doubling capacity) if required.Amortized O(1).
pop_back()Removes the last element, decrementing size by 1. It does not return the removed value; use back() beforehand if required.O(1).
size()Returns the current element count.O(1). Distinct from capacity() (allocated storage).

v.at(1)Returns the element at index 1 with bounds checking; throws std::out_of_range if invalid.O(1) with verification overhead.

[] vs at(): use [] in performance-critical code with verified indices. Use at() when indices derive from external input or have not been validated.

4. std::string vs char[]

Definition — string
A dynamically resizable sequence of characters that tracks its own length, supports growth with +=, and manages its own storage. Declared in #include <string>.
Definition — char[] / C-string
An array of char terminated by a null character '\0' (value 0) marking the end of the sequence. The terminator must be maintained explicitly; omission causes reads to continue into adjacent memory. Capacity is fixed; extension requires manual reallocation. Recognize this form in legacy interfaces; do not use it for new code.
#include <string>
#include <iostream>
int main(){
    std::string s = "  hello C++  ";
    std::cout << s.size() << "\n";   // 13; length() is equivalent
    std::string t = s.substr(2,5);   // 5 characters starting at index 2: "hello"
    size_t p = s.find("C++");        // index of first occurrence, or npos if absent
    s += "!!!";                      // appends; storage grows automatically
    std::string csv = "a,b,c";
}
MemberDefinitionExample

substr(pos, len)Returns a copy of len characters starting at index pos (zero-based)."hello".substr(1,3) returns "ell".
find(target)Returns the index of the first occurrence, or string::npos if not found. Always compare against npos.auto p = s.find("C++");
+= / +Appends (+= modifies in place) or concatenates (+ returns a new string).s += "!!!"
c_str()Returns a null-terminated view for C interfaces requiring const char*. The view is valid only while the string is unmodified and alive.fopen(s.c_str(), "r")

s.substr(0,1);  // "h"

5. map, unordered_map, set

Definition — map (associative array)
A container associating each key (e.g., "Asha") with a value (e.g., 15). std::map<string,int> ages; ages["Asha"]=15; stores value 15 under key "Asha."
Definition — ordered vs unordered
map maintains keys in sorted order (implemented as a balanced tree; O(log n) lookup and insertion). Iteration is ordered. unordered_map organizes entries by hash value (hash table; average O(1) lookup and insertion). Iteration order is unspecified. Both support identical element-access syntax.
Definition — set
A container storing unique elements. set maintains sorted order; unordered_set provides average constant-time operations with unspecified order. Insertion of a duplicate has no effect.
#include <map>
#include <unordered_map>
#include <set>
#include <iostream>
int main(){
    std::map<std::string,int> ages;
    ages["Asha"] = 15;
    ages["Ravi"] = 17;

    std::unordered_map<std::string,int> freq;
    freq["apple"]++;

    std::set<int> seen;
    seen.insert(5);
    seen.insert(5); // no effect; element already present
    std::cout << seen.size() << "\n"; // 1

    for(auto& [k,v] : ages) std::cout << k << ":" << v << "\n";
}
LineDescription
ages["Asha"] = 15;Inserts key "Asha" with value 15, or overwrites the existing value. Note: reading ages["Nobody"] also inserts a default-constructed value (0). For non-inserting lookup, use find.
freq["apple"]++;Increments the count for "apple," default-constructing it to 0 on first access. The standard counting idiom.
seen.insert(5);Inserts 5 if absent. seen.count(5) returns 1 if present, 0 otherwise.
for(auto& [k,v] : ages)Range-based iteration with structured binding (C++17): [k,v] binds the key and value of each element. auto& avoids copying.

6. Iterators

Definition — iterator
An object designating a position within a container. v.begin() returns an iterator to the first element. v.end() returns the past-the-end iterator: a sentinel marking the termination of the range, not a dereferenceable element. ++it advances to the next element; *it accesses the designated element; it != end tests for range termination.
#include <vector>
#include <iostream>
int main(){
    std::vector<int> v = {10,20,30};
    auto it = v.begin(); // designates the element 10
    std::cout << *it << "\n"; // 10
    ++it; // advances to 20
    std::cout << *it << "\n"; // 20
}

7. Algorithms — sort, find, count, transform

Definition — algorithm (STL)
A function template in #include <algorithm> operating on an iterator range [begin, end): sort, find, count, transform. The caller specifies what operation to apply; iteration and bounds are handled internally, eliminating manual loop errors.
Definition — lambda
An inline function object: [](int x){ return x*2; } defines a function accepting x and returning x*2. The capture list [] specifies which enclosing variables are accessible (empty here). Lambdas supply per-element behavior to algorithms.
#include <vector>
#include <algorithm>
#include <iostream>
int main(){
    std::vector<int> v = {5,2,9,1,5};
    std::sort(v.begin(), v.end()); // 1 2 5 5 9
    auto it = std::find(v.begin(), v.end(), 9);
    if(it != v.end()) std::cout << "found at " << (it - v.begin()) << "\n";
    int n = std::count(v.begin(), v.end(), 5); // 2
    std::vector<int> doubled(v.size());
    std::transform(v.begin(), v.end(), doubled.begin(), [](int x){return x*2;});
}
AlgorithmDefinitionResult
sort(begin, end)Orders the range (ascending by default). Requires random-access iterators (vector, deque, array).Modifies the range in place; returns void.
find(begin, end, value)Locates the first element equal to value. Returns the iterator to it, or end if absent. The result must be compared against end before dereference.Iterator.
count(begin, end, value)Counts elements equal to value.Integer count.
transform(begin, end, out, fn)Applies fn to each element and writes the result through out. The output range must have sufficient capacity.Modifies the output range.

8. using aliases and function templates (myMax)

Definition — type alias (using)
An alternative name for a type, improving readability without changing semantics. using Row = std::vector<int>; establishes Row as synonymous with vector<int>. (typedef is the legacy equivalent; using is preferred.)
Definition — function template
A parameterized function definition instantiated per argument type: template<typename T> T myMax(T a, T b) accepts two values of type T and returns the greater. At each call, the compiler deduces T and generates the corresponding specialization. This is the mechanism underlying vector<T>.
#include <array>
#include <tuple>
#include <optional>
#include <sstream>
#include <fstream>
std::pair<std::string,int> p{"score",100};
std::optional<int> maybe;
maybe = 42;

// Type aliases:
using Row = std::vector<int>;
using Matrix = std::vector<Row>;
Matrix m(3, Row(3, 0)); // 3x3 zero-initialized
template<typename T>
T myMax(T a, T b){ return a > b ? a : b; }
int m1 = myMax(3, 7);        // T=int; result 7
double m2 = myMax(2.5, 1.1); // T=double; result 2.5
LineDescription
template<typename T>Declares T as a type parameter resolved at each call site. typename indicates the parameter is a type.
T myMax(T a, T b)Declares a function accepting two values of identical type T and returning T. Mixed types (e.g., int and string) do not satisfy a single deduction.
myMax(3,7)Deduces T=int; the compiler generates and invokes int myMax(int,int). Instantiation occurs at compile time with no runtime overhead.
Principle: vector<int> is a specialization of a class template. The same mechanism supports user-defined element types: vector<Player> and map<string, Player> require no additional implementation.

Exercises

  1. Word frequency. Read one line with std::getline. Tokenize with find(' ') and substr, or with istringstream and >>. Count occurrences with unordered_map<string,int> freq; freq[word]++;. Transfer to map<string,int> for ordered output.
  2. Duplicate removal. Given vector<int> v = {5,2,9,1,5,2};, execute sort(v.begin(), v.end()); v.erase(unique(v.begin(), v.end()), v.end()); and print the result. Document the function of unique and erase in one sentence each.
  3. Largest three elements. Populate a vector with 10 values. Research nth_element for partial ordering, extract the three largest, and compare its efficiency against full sort for large inputs.
  4. Associative container application. Implement a menu-driven directory with map<string,string> phone; supporting insertion (phone[name]=num), lookup (find with != end verification), deletion (erase(name)), enumeration (range-based for with [k,v]), and termination.
  5. Template deduction. Invoke myMax with int, double, and string arguments. Attempt myMax(3, 2.5) and analyze the compilation error: explain why a single parameter T cannot bind to two distinct types.
